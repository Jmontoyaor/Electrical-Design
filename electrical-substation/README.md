# Electrical Substation

Folder for electrical substation design and analysis material. It is organized into
four deliverables, each weighted toward the course grade:

| Weight | Deliverable | Folder |
|---|---|---|
| 5% | Single-line diagram of a substation | [`single-line-diagram/`](single-line-diagram) |
| 5% | Grounding grid design for a substation | [`grounding-grid-design/`](grounding-grid-design) |
| 20% | Control, protection, and metering system design for a substation bay | [`bay-control-protection-metering/`](bay-control-protection-metering) |
| 10% | Battery bank sizing for a substation | [`battery-bank-sizing/`](battery-bank-sizing) |

These four add up to 40% of the grade; the remaining 60% belongs to other, unlisted
deliverables of the course.

No files have been added yet; each subfolder has a placeholder README. To anex an
existing GitHub repository into one of them instead of adding files directly, run:

```
git subtree add --prefix=electrical-substation/<folder> <repo-url> main
```
