# Electrical Engineering Integrative Workshop

*(Spanish: Taller Integrador de Ingeniería Eléctrica)*

Folder for the capstone/integrative workshop course material, which brings together
topics from across the electrical engineering curriculum into a single applied
project.

## Contenido

- [`75kva-substation/`](75kva-substation) — verificación del flujo de cargas (DIgSILENT
  PowerFactory) de la subestación de 75 kVA frente a RETIE, NTC 2050 y NTC 1340, con
  un ejemplo propio resuelto por Newton-Raphson.
