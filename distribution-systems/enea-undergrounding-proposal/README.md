# Subterranización - propuesta para ENEA

Propuesta de subterranización de redes eléctricas presentada a la ENEA.

## Contenido

- `Proyecto_Final_2026-1 (1).dwg` — plano del proyecto (AutoCAD).
- `Protecto_Final_2026-1.xlsx` — hoja de cálculo del proyecto.
- `Memoria_de_calculo (2).pdf` — memoria de cálculo.
- `Memoria_de_calculo.zip` — fuente en LaTeX de la memoria de cálculo (`main.tex` + capturas).
- `L01.pdf`, `L02.pdf` — láminas del proyecto.
- `analisis.txt`, `analisis.xls` — análisis adicional.

> Nota: se excluyó el archivo `.bak` del plano (copia de seguridad automática de
> AutoCAD, redundante con el `.dwg`).
