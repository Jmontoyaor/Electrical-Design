# Sistema eléctrico - asentamiento en Manizales

Proyecto de diseño de un nuevo sistema eléctrico completo para un asentamiento en
Manizales (red de distribución, acometidas y demás infraestructura eléctrica desde cero).

## Contenido

- `plano Final manizales- Asentamiento.dwg` — plano del sistema eléctrico (AutoCAD).
- `Memoria_de_calculo__asentamiento (1).pdf` — memoria de cálculo.
- `Cuadro de cargas distribución.xlsx` — cuadro de cargas de distribución.
- `disered-analysis/` — resultados del análisis en DIgSILENT/DISERED por transformador
  (`TR1`…`TR14`, cada uno en `.txt` y `.xls`).

> Nota: se excluyó el archivo `.bak` del plano (copia de seguridad automática de
> AutoCAD, redundante con el `.dwg`).
